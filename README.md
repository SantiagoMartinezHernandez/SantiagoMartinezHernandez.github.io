## 🧠 Overview
This repository hosts the personal portfolio, research showcase, and interactive portal system for **Andrés Santiago Martínez Hernández**, focusing on:
- **Digital Neuroscience & Neurotechnology**
- **Physical AI & Closed-Loop Wearable Robotics**
- **ART/Wear**: Smart mechatronic garment for real-time tremor suppression
- **Digital Health, Biomedical Engineering & AI Consulting**

## 📂 Project Architecture
- `index.html`: Main flagship landing page featuring interactive neural canvas, hero profile, ART/Wear showcase, and 4 wing portals.
- `artwear.html`: Detailed ART/Wear venture page, mechatronic architecture, and metrics.
- `neuroscience.html`: Computational & digital neuroscience research, signal processing, and publications.
- `robotics.html`: Physical AI, neuromodulation, biomechatronics, and assistive hardware.
- `journey.html`: Timeline of education, honors, grants, and career milestones.
- `health.html`: Digital health applications and clinical translation.
- `labs.html`: Research groups, affiliations, and collaborations.
- `assets/`: Styling, modular vanilla JS engine, neural canvas simulation, images, and documents.

## 🛠️ Local Development
Run a local preview server with:
```bash
# Using Node / npx
npx serve .
# Or with hot reloading
npx live-server

# Or with Python
python -m http.server 8000
```
